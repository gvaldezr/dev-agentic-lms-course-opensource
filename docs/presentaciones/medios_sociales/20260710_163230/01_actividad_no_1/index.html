Texto, imagen, video e interacción no hacen lo mismo

Formato cambia efecto

Un mismo tema puede presentarse de varias maneras. Cada versión provoca una respuesta distinta en la audiencia y sirve para objetivos diferentes.

  • Texto: explica con claridad
  • Imagen: resume y atrae
  • Video: muestra y emociona
  • Interactivo: invita a participar
El formato también comunica.
